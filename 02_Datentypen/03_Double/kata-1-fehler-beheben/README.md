# Kata: Fehler bei Kommazahlen beheben

`Warenkorb.java` kompiliert nicht. In jeder Zeile wurde einer `double`-Variable ein Wert gegeben, der so nicht funktioniert.

## Aufgabe

1. Behebe alle drei Fehler.
2. Ändere dabei **nicht** den Datentyp `double` — nur den zugewiesenen Wert.
3. Achtung bei `preis`: In Java werden Nachkommastellen mit einem Punkt geschrieben, nicht mit einem Komma!
4. Wähle für jede Variable einen sinnvollen Wert.

## Überprüfung

```
javac Warenkorb.java && java Warenkorb
```

Das Programm soll fehlerfrei kompilieren und drei Zeilen mit Kommazahlen ausgeben.
