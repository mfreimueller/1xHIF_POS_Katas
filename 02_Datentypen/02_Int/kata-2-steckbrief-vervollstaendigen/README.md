# Kata: Steckbrief-Zahlen vervollständigen

`Steckbrief.java` gibt drei Zahlenwerte einer Person aus, aber die dazugehörigen Variablen wurden noch nicht deklariert. Die Datei kompiliert deshalb nicht.

## Szenario

- Die Person ist 17 Jahre alt.
- Die Person hat 3 Geschwister.
- Die Person wohnt seit 12 Jahren in ihrer aktuellen Wohnung.

## Aufgabe

1. Deklariere und initialisiere im `TODO`-Bereich drei `int`-Variablen mit genau den Namen, die in den `println`-Aufrufen verwendet werden: `alter`, `anzahlGeschwister`, `wohnjahre`.
2. Wähle die Werte passend zum Szenario oben.
3. Entferne den `TODO`-Kommentar, sobald du fertig bist.

## Überprüfung

```
javac Steckbrief.java && java Steckbrief
```

Erwartete Ausgabe:

```
Alter: 17
Geschwister: 3
Wohnjahre: 12
```
