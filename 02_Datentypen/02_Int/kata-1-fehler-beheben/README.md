# Kata: Fehler bei Ganzzahlen beheben

`Punktestand.java` kompiliert nicht. In jeder Zeile wurde einer `int`-Variable ein Wert vom falschen Typ zugewiesen.

## Aufgabe

1. Behebe alle drei Fehler.
2. Ändere dabei **nicht** den Datentyp `int` — nur den zugewiesenen Wert.
3. Wähle für jede Variable einen sinnvollen ganzzahligen Wert.

## Überprüfung

```
javac Punktestand.java && java Punktestand
```

Das Programm soll fehlerfrei kompilieren und drei Zeilen mit Ganzzahlen ausgeben.
