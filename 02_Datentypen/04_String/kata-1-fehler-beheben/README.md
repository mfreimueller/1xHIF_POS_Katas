# Kata: Fehler bei Texten beheben

`Begruessung.java` kompiliert nicht. In jeder Zeile wurde einer `String`-Variable ein Wert gegeben, der so nicht funktioniert.

## Aufgabe

1. Behebe alle drei Fehler.
2. Ändere dabei **nicht** den Datentyp `String` — nur den zugewiesenen Wert.
3. Denk daran: Texte (`String`) stehen in doppelten Anführungszeichen `"..."`, nicht in einfachen `'...'`.

## Überprüfung

```
javac Begruessung.java && java Begruessung
```

Das Programm soll fehlerfrei kompilieren und drei Zeilen mit Text ausgeben.
