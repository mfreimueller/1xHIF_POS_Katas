# Kata: Fehler bei booleschen Werten beheben

`Tuerstatus.java` kompiliert nicht. In jeder Zeile wurde einer `boolean`-Variable ein Wert vom falschen Typ zugewiesen.

## Aufgabe

1. Behebe alle drei Fehler.
2. Ändere dabei **nicht** den Datentyp `boolean` — nur den zugewiesenen Wert.
3. Wähle für jede Variable einen Wert (`true` oder `false`), der zum Namen der Variable passt.

## Überprüfung

```
javac Tuerstatus.java && java Tuerstatus
```

Das Programm soll fehlerfrei kompilieren und drei Zeilen mit `true`/`false`-Werten ausgeben.
